Welcome to The Daily NPM, a premium developer intelligence platform styled after vintage newspaper prints. Built for creators, builders, and curators who need real-time data dispatches, predictive modeling, and watchlist tracking for the Node.js package ecosystem.

Available as a high-fidelity web application and a responsive terminal-based Telegraph TUI.

---

## Key Editions & Features

### The Front Page (Package Reports)
* **Real-time Dispatches**: Instantly fetch live version releases, licensing metadata, and star counts straight from registry wires.
* **Weekday Pacing**: View structured tables outlining weekday vs. weekend build pacing to understand project velocity.
* **AI Bureau Verdicts**: Read dynamic, automated reviews and architectural health ratings from our AI editor summarizing the package’s advantages and potential risks.

### Market Exchange (Package Comparison)
* Put packages head-to-head.
* Compare historical download volumes and forecast predictions on a clean, double-bordered comparison board.
* Preloaded preset benchmarks for major build ecosystems (UI Frameworks, HTTP Servers, State managers, and Build tools).

### Reader Portfolio & Watchlist
* **The "Dow NPM" Index**: An aggregated financial index that combines downloads across your entire watchlist, rendering a portfolio performance graph.
* **The Watchlist Gazette**: A personalized news wire that translates raw download pacing, version revisions, and alert breaches into readable vintage-style editorial stories.
* **Active Guard Rules**: Configure custom triggers to get immediately notified on:
  * *Download Shocks* (WoW drop exceeds X%).
  * *Star Milestones* (crosses target star counts).
  * *Release Watches* (new versions published).

### Predictive Forecasting Simulator
* Toggle between three predictive models: **Seasonal Linear**, **EMA Trend**, and **Quadratic Curve**.
* Adjust forecast window sliders (7 to 30 days) with visual confidence intervals.
* Run simulated growth/decline shock vectors (Flat additions, compounding multipliers, or sudden shocks) to see how models adapt.

## The Telegraph Terminal TUI
A full-featured, full-screen Node telemetry journal that operates directly inside your terminal emulator.

* **Account Session Sync**: Log in (`L`) inside the TUI to sync your watchlists. Supports local session persistence.
* **Bookmark Toggles**: Toggle tracking (`T`) to bookmark assets straight from terminal command buffers.
* **Ascii Forecasts**: Responsive ASCII rendering of index charts and trend curves.
* **Prompt Simulations**: Run simulation growth scenarios (`U`) inside the terminal.

*To launch the Terminal TUI directly:*
```bash
npx -y dailynpm tui react
```
